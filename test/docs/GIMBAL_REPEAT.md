# Pitch / Yaw 小范围往返

保留当前补偿表、补偿开关和kp/kd。测试不采表、不调参，先到下端点，再持续上端点→下端点往返，直到取消。角度连续变化，不是一度一停。

## 命令

串口115200，命令以换行结束：

| 命令 | 动作 |
| --- | --- |
| `pe` | 使能Pitch，选择Pitch波形；不启动运动测试 |
| `ptest` | 默认25→41→25反复，5°/s |
| `ptest 25 35 5` | 实测25～35°反复，命令速度5°/s |
| `ptest 40 41 5` | 针对40～41°反复 |
| `ptest 39.5 40.5 2.5` | 支持小数端点和速度，无1°步进要求 |
| `pcancel` | 取消Pitch往返或pscan，保留命令位置保持与补偿开关 |
| `pd` | 停用Pitch、撤力 |
| `ye` | 使能Yaw，选择Yaw波形；不启动运动测试 |
| `ytest` | 围绕本次启动时的实际位置±10°反复，5°/s |
| `ytest -10 10 5` | 在已有零点坐标的−10～+10°反复，5°/s |
| `ycancel` | 取消Yaw往返并保持 |
| `yd` | 停用Yaw、撤力 |
| `gd` / `stop` | 两轴停用，测试取消 |

带参数格式统一为：`ptest/ytest 下端角度 上端角度 速度`，角度相对各轴首次使能建立的零点；只有无参数ytest取本次实际位置为中心。不改变已有零点。

先正常使能，等原有使能过程结束再发测试命令。端点必须是有限数字、下端小于上端，速度为有限正数；Pitch上端不能超过当前41°配置；不增加领先量、停滞、力矩或稳速筛选条件。沿用原有电机故障与反馈失效处理。

按实际经过端点才换向，命令不重置。端点不是硬行程限位，实际可能过冲。取消冻结命令位置，原kd继续减速；pd/yd是撤力。手动目标、速度或增益命令接管对应轴时取消往返，Pitch改前馈也取消；再使能不会续跑。

ptest接替正在运行的pscan/pcal；pscan/pcal接替ptest。旧逐点校准仍与Pitch测试互斥。Yaw和Pitch各自独立，日志显示最后选中的轴。

## 怎么看

VOFA继续使用已有DMA输出，约20ms一行；Pitch保留MCU时间，Yaw精简帧不输出时间。ptest/ytest自动选择对应轴并切到电机波形。pe/ye也选择轴；如果之前在看IMU模式，先发`imu 0`切回电机波形。

Pitch专用输出前10列含义保持：目标°、命令°、实际°、速度°/s、反馈力矩N·m、发送前馈N·m、MCU毫秒、阶段、反馈有效、反馈年龄毫秒。

往返运行时阶段1=就位、3=角度增大、5=角度减小；取消后停止往返，Pitch第8列回到原扫描状态。11～14列仍为Pitch校准状态、采样状态、最后采样时间、查表有效；第15列轴标识固定为1。Yaw已改为独立9列，见[YAW_INERTIAL.md](YAW_INERTIAL.md)，不再输出Pitch校准信息。

Pitch看卡住期间的第6列即可确认前馈，不必暂停MCU。调试器可读：

- `g_pitch_test.applied_t_ff_nm`：Pitch当前发送前馈。
- `g_pitch_ff_debug.approach_sign/lookup_valid`：最后一次查表方向、有效状态。
- `g_gimbal_repeat[1]`：Pitch范围、速度、方向、active；`[0]`是Yaw。
- `g_yaw_test`：Yaw命令、实测位置/速度、kp/kd（带rad的字段单位为弧度，乘57.29578换成度）。

停止后的变量不是历史记录；动态过程用VOFA。运动中暂停MCU会停止控制更新，不能把暂停后的表现当作正常运行。

## 第一次使用

烧录新固件后，RAM补偿表会丢失：`pe` → `pcal`完成 → `ptest 25 35 5` → `pcancel`。再用`ptest 40 41 5`看局部，仍用`pcancel`保持。Yaw：`ye` → `ytest` → `ycancel`。测试期间不重建或修改补偿表。

构建与模拟只验证程序逻辑，不代表实机效果。沿用`tests/pitch_continuous/run.ps1`验证往返、命令连续性、补偿保留、取消/手动接管、失联退出及原扫描校准流程。
