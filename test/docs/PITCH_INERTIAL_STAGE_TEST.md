# Pitch 空间俯仰保持：首轮实机验收

状态：代码与主机验证，不代表已完成实机验收。Yaw 小角度残差仍未解决；本次不修改 Yaw 惯性算法和 Pitch 补偿表/参数。

## 控制链与坐标

`pmode 0` 保留原编码器链。`pmode 1`：有效四元数 → 炮口前向的空间仰角 → 以当前 Pitch 转轴求最近编码器增量 → 限幅后的编码器目标 → 原速度规划 → 原 MIT PD + 原重力/摩擦补偿。

不使用 Yaw 的外部力矩 PD，不新增积分/boost。Pitch 与 Yaw 模式独立。进入时捕获当前空间仰角，编码器目标/规划命令捕获当前实测位置，不执行旧目标；不会重设开机编码器零点。切换保证位置指令不跳到远处，不保证负载下切换瞬间力矩完全连续，需实机观察。

IMU 原生坐标：X 炮口前向、Y 左、Z 上；四元数为 body→NWU world。当前安装按 p_enc 与显示 imu_pitch 增量同向，默认 `PITCH_ENCODER_ROTATION_SIGN=+1`，即逻辑编码器正转为绕传感器 +Y 转动。空间仰角正方向向上，`goal/elev` 与 VOFA `imu_pitch` 符号相反。所有内部计算使用 rad，串口角度使用 deg。

不直接相减欧拉 Pitch：令 R 为当前四元数旋转矩阵，原生 +X 炮口沿 Pitch 轴转动 d 后的世界竖直分量为 `R20*cos(d)-sign*R22*sin(d)`。求达到捕获仰角的最近 d。Yaw/Roll 扫描已用独立四元数合成验证；转轴接近竖直、仰角超过 ±80°或目标几何不可达时退出空间模式，不能将此实现解释为任意翻滚姿态均可保持。

## 指令与状态

- `pe`：启用 Pitch，等待约 1 s 到 ACTIVE。
- `pmode 0`：回到编码器模式，捕获当前编码器位置。
- `pmode 1`：捕获当前空间仰角并保持。
- `pprobe`：只读状态，返回 `#PP`；pmode 请求也自动排队返回状态。终端 yaw_capture.py 已增加 #PP 显示，重启脚本生效；VOFA 原九列不变。
- `pd`：停用 Pitch；不会自动停用或切换 Yaw。

`#PP` 的 state=4、fault=0、mode=1、valid=1、reason=0 才表示当前空间保持已运行。valid/age 为报告时的 IMU 有效性/年龄；goal=捕获仰角，elev=当前仰角，enc=机械编码器，target=修正后的编码器目标，delta=本周期几何修正，gain=空间仰角对编码器角的局部导数，limited=目标被限位截断。年龄单位 ms，角度单位 deg。mode 0 下 goal/delta 可保留上一空间会话信息，不是正在执行的空间目标。

reason：0 正常，1 Pitch 未 ACTIVE/电机反馈不可用，2 扫描/校准/自动往返忙，3 IMU 无效或超过 5 ms，4 IMU 重标定/参考系变化，5 几何退化/数值无效，6 编码器范围不允许。mode 1 下 p/pr/pscan/pcal/自动往返拒绝执行；先 pmode 0 再使用原命令，不将 p/pr 悄悄解释为空间角度。

IMU 失效、数据过期、参考系变化或几何退化时：丢弃姿态修正，自动回 mode 0，编码器捕获当前位置，继续原 PD 和重力支撑，并排队报告退出原因；不会自动重进 mode 1。电机/CAN/过温故障仍按原机制停用。IMU 重校准应在退出空间模式后进行。

## 首次烧录后步骤

1. 先确认机械中位及余量；初测可保留 Yaw mode 0，减少同时变化的因素。Pitch 原软件目标范围是相对开机零点的 -100°～41°，不是带绝对机械零点的硬件限位。空间模式会同时限制 target 和 command，但不能弥补开机零点与实际机械安全范围不一致。不要在机械端点附近首测。
2. pe，等待 ACTIVE，pmode 0；保持原补偿和 PID。若当前位置需要调整，仅在已确认安全的坐标内用原 p 指令到中位。不要无条件将开机任意姿态下的 20°当作安全中位。
3. 用 VOFA 或已有调试器确认小幅 Pitch 编码器正增量与显示 imu_pitch 同向、与空间仰角反向；板子随 Pitch，安装轴向符合上述约定。若不符，先 pd，报告方向，不盲目进入闭环。数据全零不视作有效性证明。
4. 停稳后 pmode 1、pprobe。确认 mode=1/valid=1/reason=0，切换时炮口无明显跳动。保持底座静止约 10 s，观察空间角、编码器与明显抖动。
5. 缓慢让底座抬头/低头约 ±1°，稳定后最多扩大至 ±2°。预期炮口相对房间仰角接近不变，Pitch 相对底座反向运动；pprobe 的 goal 不变、target 随扰动修正。无 PID 调整，不做快速大幅 Yaw/Roll 或 180°运动。
6. 出现同向放大、明显振荡或接近机械端点：pd。若 limited=1，说明现有机械行程不能继续补偿，不判为保持通过。
7. 小扰动后 pmode 0、pprobe，确认捕获当前位置、无远目标跳转；最后 pd。测试不自动退出或修改 Yaw 模式。

请返回：切换前后及底座抬头/低头时的 #PP、VOFA 空间角/编码器变化，以及目视是否跳动/抖动。无需运行 Yaw ybench，也不要求完整导出 1024 帧。
