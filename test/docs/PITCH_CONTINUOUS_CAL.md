# 连续扫描采集上下行力矩

先 `pe` 使能，再发一次 `pcal`：关闭补偿采集，自动按实测角度 **0→41→0** 走一遍，生成表后直接开启1.0倍补偿并保持。没有自动复扫；随后发 `pscan` 比较效果，扫描不会关闭补偿。

表只在RAM中，断电丢失。不自动调kp/kd，不写Flash。重新 `pcal` 会清空本次表并重新采集。

## 采什么

`pitch_cont_table[42]` 对应实际0、1、…、41°。上行每个节点第一次经过记up，下行第一次经过记down。

例如两份反馈实际24.98°与25.03°，用对应的两份力矩线性插值得到25°的力矩。使用实测角度，绝不使用目标角度。采样直接读新反馈，不依赖20ms串口发送。

每份反馈帧号只处理一次。`samples_seen` 是处理数，`feedback_skipped` 是未处理到的反馈数。没有速度、力矩波动、等待时间、最少样本数或反馈间距筛选。只要两个实际反馈夹住节点，就插值；因此快速冲过时的力矩同样会入表。无法计算的NaN/Inf不参与插值。

每个节点分别有 `up_valid`、`down_valid`；缺测值为NaN，不当零。双向都有数据才计算：

- `gravity_nm = (up_nm + down_nm) / 2`
- `friction_nm = (up_nm - down_nm) / 2`

这里的G/F是上下行力矩的和差估计；本版不分离起停、换向、加速等动态力矩。

## 怎样使用

前馈按当前实际角度，在相邻有效节点之间线性插值；上行使用up，下行使用down，等价于对应方向的G±F。单方向已采到的节点也可用于该方向，缺少另一方向不影响它的使用，但不生成这个节点的G/F。

不外推，不用目标角度填缺测，不回退到旧表。查不到对应方向数据时发送前馈0。新表没有额外的3N·m限幅或1N·m/s变化率限制，协议本身的编码范围不变。

采集完成启用补偿时，将对应支撑从P项转交给前馈，避免两者重复叠加；随后保持最后前馈值，新的运动恢复按角度查表。扫描开始、换向和结束都不改补偿开关。`pff 0` / `pff 1` 由用户切换，`pcancel` 保持，`pd` 停用撤力。

## 在哪里看

调试器查看：

- `pitch_cont_table`：每个实际角度的up、down、G、F及valid。
- `g_pitch_cont.up_nodes/down_nodes/valid_nodes`：上下行及双向共同节点数量，各最多42。
- `g_pitch_cont.summary`：完成/取消摘要，中文UTF-8。
- `g_pitch_scan.end_summary`：扫描结束原因及补偿开关、保持状态。

VOFA前10列不变。追加列：11校准状态（0空闲、1采集、3完成、4取消），12最近反馈是否无法计算（0正常、1非有限数），13最近采样的MCU接收时间，14最后一次前馈查表是否有效。保持时第14列保留最后查表状态；第13列在采集结束后停止更新。

保存VOFA原始数据看速度尖峰和瞬时力矩；不另建异常缓冲、统计报表或自动比较指标。20ms波形可能漏掉更短尖峰，实际采样按新反馈执行。

验证脚本 `tests/pitch_continuous/run.ps1` 沿用现有GCC/HAL模拟。检查单次往返、实际角度插值、重复反馈去重、无速度/力矩筛选、缺测NaN、全量前馈、重复扫描保留开关、取消和原有反馈故障处理。仍需上板验证机械表现。

## 这次波形怎样对照

pscan始终按5°/s推进命令；pcal复用同一轨迹，但关闭前馈重新采表，结束后启用新表。夹在两次pscan中间的pcal改变了表，因此左右两次pscan不一定使用同一份补偿。第8列仅标记运动阶段；第11列为1才是正在采集。g_pitch_scan.start_summary现在明确区分pscan/pcal及真实启动前馈开关。

原来0～5°查不到补偿，本次扩为0～41°共42点。0°也必须由真实反馈取得，缺测仍为NaN/valid=0，不能用1°替代。首次pcal本身仍无补偿，不承诺首轮起步尖峰消失。停止保留命令位置与最后前馈，停止后的实际角度可能继续变化后达到平衡；没有强行将实测锁到命令。

速度直接来自电机反馈，当前12位、−30～30rad/s解码，每档约0.8395°/s，静止编码可能是−0.4197°/s。小阶梯包含量化，大尖峰不能只归因于量化。本次不加滤波、不改速度比例和kp/kd。

命令与实测都出现台阶时，先保存原始CSV。第7列是MCU毫秒，同一方向运动中应有：命令角度差约等于 ±0.005 × 时间差毫秒。正常20ms记录对应约0.1°。若时间间隔变大，按样本序号画图会压缩这一段时间；只凭截图不能区分发送/接收缺行和控制循环间隔变长。也不能仅凭小位置误差认定实际速度平稳。
