# Pitch 往返扫描

USART2：115200、8N1，每条命令带换行。

- `pe`：使能，不启动扫描。首次使能捕获零点，普通 `pd/pe` 不改变已有零点。
- `pscan`：从当前位置自动就位，然后按实测角度 **0→41→0**，一次往返后保持。命令推进速度为5°/s，实际速度看波形。不再有20°/s第二组。
- `pscan` 不改变补偿开关：`pcal` 完成后已开启的补偿会继续使用；`pff 0` 后扫描仍为关闭；`pff 1` 后扫描仍为开启。
- `pcancel`：取消扫描并保持，保留补偿开关。`pd`：停用撤力。再次使能不续跑。
- 手动角度命令仍先取消扫描，再按原语义执行。

实测端点配置在 `Core/Application/Module/Gimbal/gimbal.h`：`PITCH_SCAN_MIN_ACTUAL_DEG=0`、`PITCH_SCAN_MAX_ACTUAL_DEG=41`。这是换向位置，不是硬行程限制。按实测经过端点才换向，命令角度可以超过端点；换向只改变推进方向，不重置命令角度。

已移除扫描专用的领先量、停滞、速度、力矩、停止余量和行程越界中止条件。原有电机使能、故障和反馈失效处理保持不变。

调试器看 `g_pitch_scan.start_summary/end_summary`。纯数值VOFA中不混入中文摘要；中文按UTF-8显示。

VOFA前10列：目标角度°、命令角度°、实测角度°、实测速度°/s、反馈力矩N·m、发送前馈N·m、MCU毫秒、扫描阶段、反馈有效、反馈年龄毫秒。

阶段：1就位、3上行、5下行、10完成保持、11取消保持、12故障退出。约20ms发送一行，DMA忙会跳过发送，应按MCU时间看间隔。后4列见连续校准说明。

第一次测试：烧录后 `pe` → `pscan` 保存无补偿波形 → `pcal` 完成采集 → `pscan` 保存补偿后波形。需要重复对比时用 `pff 0` / `pff 1` 自己选择补偿，再发 `pscan`。两次都只进行5°/s往返。

构建与主机模拟不代表实机已经跑通；实机覆盖情况以实际角度及节点valid为准。

装车上端统一配置在 `pitch_continuous_cal.h` 的 `PITCH_CONT_MAX_DEG=41`，`gimbal.h`的扫描端点引用它。连续校准为0～41°共42个节点；旧5°打点只到40°。手动绝对/相对Pitch目标超过41°时取41°，自定义ptest上端超过41°会拒绝。内部PD命令不被封死到41°，避免重新出现有负载时到不了实测端点的问题。41°是扫描换向点，实机过冲仍需看波形。
