# Yaw 摩擦前馈修复与阶段验收（2026-10-27）

## 本次唯一控制改动

现有摩擦前馈的目标不再乘 drive 或低规划速度。位置规划、MIT PD、标定表、
1 N·m/s建立斜坡、±1 N·m补偿限制、±1.5 N·m估算总量约束、位置边界和故障停用不变。
新文件 `yaw_friction_goal.c/h` 只是已有前馈的目标/退出选择器，不计算另一条补偿力矩。

- 新目标尚差大于0.10°时允许开始纠偏；未到位且无需制动时向纠偏方向的原有F建立。
- 依据原规划器的制动距离判断是否需撤补偿；制动结束、仍未到位时允许重新建立。
- 真正进入原有到位条件后撤补偿。之后误差需超过0.15°才重新启用，0.05°迟滞大于约两个编码器量化格。
- 制动退出也留0.05°距离迟滞，或在朝目标速度进入原有零码时解除制动状态。
- 换向仍先清理旧方向摩擦尾项，再按原斜坡建立反方向力矩；停用、故障、模式切换和目标Reset清理选择状态。
- 积分、boost继续关闭。非普通编码器定位的原有分支保持原样。

这不保证严格零误差；本轮临时验收标准是约±0.5°。若负载使有界F仍不足，
可能保留非零纠偏力矩和残差，不继续叠加积分/boost去追内部0.10°到位带。

- 标准模型：0°↔0.5°、5与20°/s各三轮，0°↔10°、20°/s三轮，正反电机方向通过。
  末段残差约0.10°，无模型过冲或持续摆动。
- 5 ms反馈、真实位置/速度/力矩量化模型通过；小角度残差约0.085～0.087°，大角度返回末段波动约一个位置量化格。
- 另测较高干摩擦模型时残差可约0.17°，仍满足本阶段±0.5°，不由此修改标定F。
- 已检查未到位静止、明确制动、到位迟滞、换向、无效输入、手动停用、CAN TX失败与反馈超时。
- 原Yaw负载集成正反方向测试通过，原先的停止前馈回零断言也通过；惯性正反方向回归通过。
- 诊断开关前后CAN字节一致性、采样/导出回归通过。主机模型不代替真实摩擦/间隙/驱动验收。

## 实机自动测试

只有操作员输入 `ybench` 才自动发运动指令；程序启动不自动使能或运动。
使用原 `C:\Users\zzx\yaw_capture.py` 的COM参数重新启动终端，先关闭旧终端/VOFA。
需要本轮固件新增的只读 `yprobe <id>` 状态响应；旧固件无响应时测试会拒绝开始。

固件烧录前保存尚未落盘的Pitch RAM标定表。本轮不改Pitch表或控制。

```text
ye
ymode 0
ybench
```

`ye` 后等轴进入ACTIVE再继续。完整测试内容：

1. 回到绝对目标0°并检查保持。
2. 0°↔0.5°，5°/s三轮；回到同一0°起点。
3. 0°↔0.5°，20°/s三轮。
4. 小角度全部通过后，0°↔10°、20°/s三轮（用户已确认Yaw全周无机械行程限制）。

每个目标至少保持3秒，若名义行程较长则增加保持时间；每条目标使用 `y`，不累加 `yr`。
只做小角度用 `ybench small`；独立较大角度用 `ybench large`。
`yd`、`gd`或 `ybench stop` 可取消；自动测试结束或异常会发送 `yd` 撤力。
串口断开导致无法送达yd时，终端会明确提示人工确认停机，不能把“已发命令”当作实际停用。

测试不调整任何增益、FF、积分或boost开关；模式、开关或新鲜度不符会拒绝。
过程中拒绝其他控制命令，保留紧急停止。较远起点会要求先手动回到0～10°附近，避免误扫大范围。

普通九列遥测持续保留；测试仅额外按需请求状态，不自动录制/导出1024帧。
正常结果保存在 `yaw_logs/yaw_bench_*.csv` 和 `.json`：每条指令、逐次残差、
末500ms摆幅、过冲、估算峰速及前后状态均有记录。
异常时停止后续行程并保留这些数据；确认安全后复现异常时，再按旧流程使用 `ydiag`。

## 自动判定与人工确认

- 末500ms每点位置误差≤0.5°，峰峰摆幅≤0.10°。
- 小角度过冲≤0.25°，较大角度过冲≤0.5°。
- 一轮实际往返幅度至少达到命令幅度的一半，避免0.5°指令根本不动也因±0.5°容差被判通过。
- 遥测断流超过0.5秒、轴不再ACTIVE、模式/目标不符、越出本段边界或任一检查失败均停止。
- 峰速由编码器增量与MCU遥测发送间隔估算，只做证据记录；规划速度不是机械速度的硬限速。
- 自动通过只代表编码器及上述临时指标通过，还需操作员确认实际炮口无明显抖动、异常声响或冲击。

软件零点仍是首次使能位置，重启后的0°不等于固定机械零点。
前后对比保持同一机械姿态/区间，可用状态响应中的原始电机位置raw核对。
